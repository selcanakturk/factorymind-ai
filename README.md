# FactoryMind AI

FactoryMind AI is an intelligent manufacturing portfolio project that will combine multiple machine learning systems to help factory operators understand machine health, anticipate failures, detect abnormal behavior, and identify product defects.

## Project vision

The long-term goal is to build an end-to-end manufacturing intelligence platform. Development will proceed incrementally, beginning with clear, hands-on data exploration and baseline modeling before adding application architecture, services, user interfaces, and MLOps practices.

## Planned machine learning modules

- **Predictive maintenance:** Estimate failure probability, failure type, machine health, and maintenance risk from operational and sensor data.
- **Remaining useful life:** Model degradation over time and estimate the operating life remaining for a machine or component.
- **Anomaly detection:** Learn normal operating behavior and identify unusual sensor patterns.
- **Computer vision quality inspection:** Detect and localize manufacturing defects in product images in a later phase.

## Current status

**Early development — Day 0 / project initialization.**

The current focus is preparing for exploratory data analysis of the AI4I 2020 Predictive Maintenance Dataset. No models, backend, frontend, or deployment infrastructure have been implemented yet.
